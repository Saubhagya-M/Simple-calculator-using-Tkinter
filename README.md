# 🧮 Simple Calculator using Tkinter

A lightweight desktop calculator application built with **Python** and **Tkinter**. The project demonstrates how to create a graphical user interface (GUI), handle user input, connect buttons to application logic, and perform basic arithmetic calculations.

## 📌 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🧹 Clear/reset functionality
* 🖥️ Interactive graphical user interface
* ⚡ Instant calculation through button-based input
* ❌ Basic handling of invalid calculations

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter** – GUI development
* **Python standard library**

## 🚀 Getting Started

### Prerequisites

Make sure **Python 3.x** is installed on your system.

Check your Python installation:

```bash
python --version
```

Tkinter is generally included with standard Python installations. If it is not available on your system, install the appropriate Tkinter package for your operating system.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Saubhagya-M/Simple-calculator-using-Tkinter.git
```

2. Navigate to the project directory:

```bash
cd Simple-calculator-using-Tkinter
```

3. Install the project dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

## 💡 How It Works

The application uses **Tkinter widgets** to construct the calculator interface.

The basic workflow is:

1. The user enters numbers and operators using the calculator buttons.
2. The application stores the selected input as an arithmetic expression.
3. When the user requests a calculation, the expression is evaluated.
4. The resulting value is displayed in the calculator interface.
5. The clear functionality allows the user to reset the current calculation.

This project provides practical experience with **GUI development, event-driven programming, functions, user input handling, and Python application structure**.
